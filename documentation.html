HumanLang Documentation

A beginner-friendly programming language that reads like natural language

1. Basic Structure

A HumanLang program is made up of commands written in a simple, natural language format. These commands perform actions like printing messages, getting user input, making decisions, and controlling loops.

2. Syntax and Commands

2.1 Print (say)

say "Hello, World!"

Explanation: Prints the string to the console.

2.2 Input

wait for the user to type something, and call it user_name

Explanation: Takes user input and stores it in user_name.

2.3 Variables

wait for the user to type something, and call it my_name
say "Hello, " + my_name

2.4 Conditional Statements (if-else)

if my_age < 18:
    say "You are a minor."
else:
    say "You are an adult."

2.5 Loops (for)

for i from 1 to 5:
    say i
end for

3. Example Program

// Greet the user
say "What is your name?"
wait for the user to type something, and call it user_name
say "Hello, " + user_name

// Ask for the user's age
say "How old are you?"
wait for the user to type something, and call it user_age

// Conditional check
if user_age < 18:
    say "You are a minor."
else:
    say "You are an adult."

// Counting loop
say "Counting from 1 to 5:"
for i from 1 to 5:
    say i
end for

// Goodbye
say "Goodbye!"

4. How HumanLang Works

  • Interpreter: Reads each line and performs the described action.
  • Variables: Automatically inferred and declared when used.
  • Execution: Top-down, unless controlled by logic like conditions or loops.

5. Error Handling

error: unknown variable "name"
error: expected 'end' but found 'else'

6. Key Concepts

  • Commands: Represent logic (e.g., say, wait for, if, for)
  • Variables: Store and manage data
  • Flow Control: Use conditionals and loops

7. Conclusion

HumanLang is a simple and expressive programming language that reads like English. It’s an ideal way to learn programming logic without complex syntax. Have fun experimenting and building with it!
